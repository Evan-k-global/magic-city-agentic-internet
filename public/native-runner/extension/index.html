Magic City Runner Extension

This staging package pairs your browser with Magic City using a short-lived code. The extension stores the device token locally and checks for waiting missions; browser work starts only from an explicit run action.

Public users should install the signed Chrome Web Store extension. This page remains as the internal staging fallback until the store listing is live.

  1. Use the extension folder inside the Magic City repo: <repo root>/public/native-runner/extension. In this workspace, open Documents/Codex/agent-verification/public/native-runner/extension.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select public/native-runner/extension.
  4. Open Magic City Settings, click Pair, then paste the code into the extension popup.
